# 🛡️ 안심거래 (Ansim-Market)
> 중고거래 판매자 신고 조회 및 사기 피해 예방 서비스

최근 중고거래 이용률이 증가하면서 사기 피해 사례도 함께 늘어나고 있습니다. 안심거래는 거래 전 상대방의 닉네임이나 연락처를 간편하게 검색하여 사전에 신고 이력을 조회하고, 피해 사례를 공유할 수 있도록 돕는 웹 서비스입니다.

## 주요 기능

### 1. 회원 관리 (Authentication)
* 회원가입: 이메일과 비밀번호를 입력하여 간단하게 가입할 수 있습니다.
* 로그인: 가입된 계정 정보를 대조하여 인증하며, 로그인 완료 시 메인 대시보드와 기능 메뉴가 활성화됩니다.
* 상태 유지: 브라우저를 새로고침하더라도 로그인 상태가 유지됩니다.

### 2. 판매자 검색 및 신고 이력 조회 (Search)
* 통합 검색: 판매자의 닉네임이나 연락처(전화번호)를 입력하여 빠르게 검색할 수 있습니다.
* 피해 건수 및 내역 확인: 해당 판매자에게 누적된 신고 건수와 최근 3건의 신고 상세 사유 및 등록 일시를 일목요연하게 제공합니다.

### 3. 사기 피해 신고 등록 (Report)
* 간편 등록: 사기 이력이 의심되는 판매자의 정보(닉네임/연락처), 신고 사유, 상세 내용을 작성하여 제출합니다.
